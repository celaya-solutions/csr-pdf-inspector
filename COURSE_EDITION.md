# PDF Inspector: Research Course Edition

This is the Celaya Solutions Research Course Edition for the full-stack capstone project catalog.

This is a Rust and WebAssembly library. Students must design a real backend and persistent data flow before it can pass the capstone.

It is a Challenge project. It does not receive the shared Node, Hono, SQLite, Railway, and Vercel contract. A student must get instructor approval and write a deployment plan before selecting it.

Use fake data only. Do not enter customer, health, payment, account, or private contact information.
